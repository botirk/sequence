# Sequence
* Тренажёр изучение последовательностей
* Предмет последовательности это Картинка/Текст/Картинка+Текст
* Тренажёр использует локальную папку пользователя для хранения последовательности
* Дополнительно тренажёр может использовать дистанционную папку для последовательноости (только на чтение)
* Тренажёр не требует компиляции и весь исходный код в нём открытый и не сжатый
* В тренажёре нет никакого отслеживания пользователя
* Тренажёр будет в русском и английских языках
